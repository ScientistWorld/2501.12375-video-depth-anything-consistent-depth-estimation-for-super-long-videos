# Scoring Constraints

To make scores comparable, future methods must hold the following fixed for the `synthetic_long_video` experiment:

- Use the 128-frame RGB frames and ground truth generated by `data/synthetic_rgbd.py` with the default seed and dimensions used by the scripts.
- Write prediction artifacts as `.npz` files containing a `prediction` array with shape `[frames, height, width]`.
- Do not train or tune on the ground-truth depth for the evaluation video.
- Do not change metric definitions, masks, alignment, or the fixed constraint metrics in `eval/metrics.py`.
- Report parameter count and video training-frame count honestly if changing the model or training data.

The benchmark is intended to reward video-depth temporal consistency, not larger backbones, extra supervision, API calls, or direct use of the evaluation labels.
